# Visual direction
Systems in Motion: expressive engineering, with evidence at its center.
Palette: paper #f3f3ef, ink #171917, cobalt #2448ec, muted #555951. CSS tokens in globals.css.
Native sans type with oversized asymmetric headlines. Mono only for small system labels.
Selected work before biography and tools. Buttons pill-shaped, project surfaces 16px corners.
Motion explains user-selected systems. Short transitions; no scroll hijacking or perpetual typing.
Visible-by-default content, keyboard support, reduced motion, responsive layouts.
References: Dennis Snellenberg for scale, Rauno Freiberg for interaction craft, Bruno Simon for demonstrated expertise. Inspiration only; no copied code or assets.
